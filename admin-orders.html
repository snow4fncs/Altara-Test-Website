Paste a tracking number to mark an order shipped and email the customer. Review requests unlock five days after dispatch. Export to-ship CSV downloads every unshipped order in MyPost Business’s own import format — upload it via Send → Import orders, print all labels at home, drop the satchels off. On a phone the export opens the share sheet, so you can save it to Files or send it straight to the MyPost app.
